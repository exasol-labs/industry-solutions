Node context menus

Every node on the process map carries a right-click menu — filter the log by a step, drill into an attribute, read a description, open notes, run an action or drill into a sub-process. This guide walks each entry, with a bookstore example.

Open it by clicking (or right-clicking) a node on the A-Chart, B-Chart, A/B Comparison or Happy-Path map. The menu is headed by the step's name; which entries appear depends on your role, whether the Actions feature is on, and whether the map is a high-level (Σ) or drilled map.
1

The menu at a glance

A node menu for a normal analysis map looks like this:

Checkout
✓ Require in journeys
⊖ Exclude from journeys
▤ Meta Infos
≡ Show description
✎ Show Notes (2)
▷ Actions ▸

Entries you don't have the role for, or that don't apply to this node, are simply omitted — the menu only ever shows what you can actually do here.

2

Require / Exclude a step

The two filter entries add the step to the chart's include or exclude list and reload immediately — the same lists the sidebar Filters section shows.

  • ✓ Require in journeys — keep only journeys that pass through this step.
  • ⊖ Exclude from journeys — drop every journey that touches this step.

Example: Require Checkout to study only orders that reached checkout; then Exclude Cancelled to remove the ones that fell out. A step can be in one list at a time; picking the opposite action moves it.

Reset from the sidebar. Include/exclude lists clear with the Filters section's ↺ Reset, and are saved with a preset.
3

Meta Infos — filter by a case attribute

▤ Meta Infos opens a panel of the project's case attributes (META_1–3, shown with their business names) in three tabs. It lists only the values that actually occur on this node's events, each searchable, with an Include (⊕) and an Exclude (⊖) toggle.

Example: on the Payment node, open the Payment tab, ⊕ Include Visa to keep only journeys that paid by Visa, or ⊖ Exclude SEPA to drop the slow-transfer ones. Include ⊕ keeps journeys that have an event with the value; Exclude ⊖ drops journeys that have it — exactly like the step Require/Exclude, but per attribute value. Multiple values per column are allowed, and the choice is saved with a preset.

4

Show description & Notes

Two read/annotate entries appear when there is something to show:

  • ≡ Show description — the step's stored description text (from the step editor), when it has one.
  • ✎ Show Notes (n) — open the threaded sticky-notes for this node; the count is shown in the label. Anyone who can see a note may add a comment; only its author reclassifies or deletes it.
5

Actions (Power / Developer)

When an administrator has enabled the Actions feature and you hold the Power, Developer or Admin role, the menu lists the actions authored for this project whose availability matches this node. Running one shows its result (a table or a small map) in a modal, always honouring the chart's current filters.

Node-aware. An action only appears on the nodes its author scoped it to, so the menu stays short and relevant.
6

Aggregate & drill (Developer / high-level maps)

On richer maps the menu grows two more capabilities:

  • Σ Aggregate — in the aggregate designer's pick mode a developer collapses a connected group of steps into a single Σ super-step (see the Aggregates guide).
  • ⤵ Drill down — on a Σ node of a high-level map, open the detail sub-process it stands for; a drilled map carries a ← Return to high-level map affordance.

These entries only show for the roles and map types they apply to — a plain analysis map for a standard user shows just the filter, meta, description and notes entries.

Good to know

  • The menu is a filter shortcut. Require, Exclude and Meta Infos all write into the same filter state the sidebar edits — so a node action and a sidebar change stack together, and both are saved by a preset.
  • Meta Infos is node-scoped but filters whole journeys. It lists the values seen on this node, yet Include/Exclude keep or drop the entire journey that carries the value.
  • Read-only maps hide the filter entries. A simulation source, for instance, shows no Require/Exclude (there is nothing to reload).
  • Edges have a menu too. Right-click a transition to open its notes.
